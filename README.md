# SuperSimple Tally Counter
SuperSimple Tally Counter is a powerful and easy-to-use counter app for iPhone, iPad, Apple Watch, and Mac. You can use it for everything you want to count. It's simple enough to pick up and use immediately, and powerful enough to tweak it just the way you want.
